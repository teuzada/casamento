# Site de presentes de casamento

Arquivos corrigidos para a estrutura atual do repositório: todos os arquivos na raiz.

## Como atualizar
Envie e substitua os arquivos do ZIP na raiz do repositório:
- index.html
- padrinhos.html
- admin.html
- style.css
- app.js
- config.js
- admin.js
- casal.jpg

Depois atualize o site com Ctrl+F5.

Antes de receber presentes, configure a chave Pix e os dados do recebedor em config.js. Faça um teste com valor baixo. O painel ainda salva registros apenas no navegador atual e não confirma pagamentos automaticamente.
